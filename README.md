## FinalYearPro
FinalYearPro is an interactive Smart Career Roadmap and Industry Liaison System designed to streamline career planning and talent scouting for university cohorts. The platform features a personalized AI career recommendation engine, comprehensive student readiness tracking, an automated mock interview simulator, and an integrated internship board. Built using a multi-role structure, it provides tailored dashboards for students, academic mentors, and industry partners to collaborate effectively. The live working prototype of this entire ecosystem is fully encapsulated and ready to demonstrate directly within the file.
